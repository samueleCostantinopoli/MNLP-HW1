README - Description of JSONL Files (Test Results - Mediani)

---------------------------------------------------------
1. TEST SET FILES (mediani-test-*)
---------------------------------------------------------

1.1 mediani-test-distilBERT-baseline.jsonl
   - Base Model: DistilBERT.

1.2 mediani-test-miniLM-baseline.jsonl
   - Base Model: all-MiniLM-L6-v2

1.3 mediani-test-distilBERT-infoNCE-Angular.jsonl
   - Base Model: DistilBERT.
   - Training: Fine-tuned using InfoNCE loss.
   - Similarity: Angular.
   - Description: Evaluation of DistilBERT performance when using angular distance instead of standard cosine similarity.

1.4 mediani-test-distilBERT-Triplet-Cosine.jsonl
   - Base Model: DistilBERT.
   - Training: Fine-tuned using Triplet Loss.
   - Metric: Cosine Similarity.
   - Description: Rankings generated by a DistilBERT model optimized via triplet-based learning.
   
1.5 mediani-test-MiniLM-infoNCE-Cosine.jsonl
   - Base Model: all-MiniLM-L6-v2
   - Training: Fine-tuned using InfoNCE loss.
   - Similarity: Cosine.
   - Description: Dense retrieval results using a lightweight, efficient transformer model.

1.6 mediani-test-MiniLM-infoNCE-CosineReranker_bge-reranker-base.jsonl
   - Base Model: all-MiniLM-L6-v2 (Retrieve) + bge-reranker-base (Re-rank).
   - Training: InfoNCE (for the retrieval stage).
   - Similarity: Cosine.
   - Description: A two-stage pipeline. It first retrieves candidates using the allMini model and then re-ranks the top results using a dedicated cross-encoder (BGE Reranker) for improved precision.

1.7 mediani-test-bge-LargeBaseline-Cosine.jsonl
   - Base Model: BGE-Large-v1.5.
   - Similarity: Cosine.
   - Description: Baseline results using the pre-trained BGE-Large model without any specific fine-tuning on the target dataset.
   
1.8 mediani-test-bge-LargeTriplet-Cosine.jsonl
   - Base Model: BGE-Large-v1.5.
   - Training: Fine-tuned using Triplet Loss.
   - Similarity: Cosine.
   - Description: Rankings from a high-capacity model optimized to maximize the distance between positive and negative document pairs.


---------------------------------------------------------
2. BLIND SET FILES (mediani-blind-*)
---------------------------------------------------------
These files utilize the exact same models and configurations as the Test Set, but they contain the predictions generated for the "Blind" evaluation dataset.

2.1 mediani-blind-distilBERT-baseline.jsonl
   - Base Model: DistilBERT.
   -

2.2 mediani-blind-miniLM-baseline.jsonl
   - Base Model: all-MiniLM-L6-v2.
   -

2.3 mediani-blind-MiniLM-infoNCE-Cosine.jsonl
   - Base Model: all-MiniLM-L6-v2
   - Training: InfoNCE loss.
   - Similarity: Cosine.
   - Description: Dense retrieval results on the blind dataset using the InfoNCE-trained MiniLM model.

2.4 mediani-blind-MiniLM-infoNCE-CosineReranker_bge-reranker-base.jsonl
   - Pipeline: all-MiniLM-L6-v2 (Retrieve) + bge-reranker-base (Re-rank).
   - Similarity: Cosine.
   - Description: Two-stage retrieve-and-rerank pipeline applied to the blind dataset queries.

2.5 mediani-blind-bge-LargeTriplet-Cosine.jsonl
   - Base Model: BGE-Large-v1.5.
   - Training: Triplet Loss.
   - Similarity: Cosine.
   - Description: Predictions on the blind dataset from the Triplet-optimized BGE-Large model.

2.6 mediani-blind-bge-LargeBaseline-Cosine.jsonl
   - Base Model: BGE-Large-v1.5.
   - Similarity: Cosine.
   - Description: Pre-trained baseline predictions (no fine-tuning) applied to the blind dataset.

2.7 mediani-blind-distilBERT-infoNCE-Angular.jsonl
   - Base Model: DistilBERT.
   - Training: InfoNCE loss.
   - Similarity: Angular.
   - Description: Predictions on the blind dataset using DistilBERT with angular distance.

2.8 mediani-blind-distilBERT-Triplet-Cosine.jsonl
   - Base Model: DistilBERT.
   - Training: Triplet Loss.
   - Similarity: Cosine.
   - Description: Predictions on the blind dataset from the Triplet-optimized DistilBERT model.


---------------------------------------------------------
DATA FORMAT:
The files are in JSONL (JSON Lines) format. Each line is a standalone JSON object:
- Key: The unique query ID (string).
- Value: A list of integers representing the document indices, ranked by the model from most relevant to least relevant.
